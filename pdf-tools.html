🗂️ 本地 PDF 工具箱

合并多个 PDF、拆分成多个文件、提取指定页、旋转页面、拖动缩略图调整顺序。文件只在你的浏览器里处理，不会上传到任何服务器。手上只有照片或截图？先用 图片转 PDF 生成 PDF，再回到这里合并整理。

🔒 本地处理 · 不上传服务器

你选择的 PDF 只在你的浏览器中用 JavaScript 读取和生成，本页没有任何上传接口，不会发送到本站或第三方服务器。处理所用的程序库（pdf-lib、PDF.js）都放在本站，不从外部 CDN 加载；页面加载完成后断网也能继续使用，你可以打开浏览器开发者工具的 Network 面板自行验证。本站用 Google Analytics 统计匿名访问量，只记录访问了哪个页面、是否使用过工具，不包含文件名或文件内容。详见隐私政策。

使用步骤

  1. 点击上方虚线框或直接拖入 PDF。可以一次选多个，也可以分几次添加，新文件的页面会接在后面。
  2. 在“页面”区域整理：拖动缩略图改顺序（手机上用 ◀ ▶ 按钮），每页右下角可以单独旋转或删除；也可以先选中多页，再用工具栏批量旋转、删除。
  3. 选择导出方式：
    • 合并 / 重新排序：点“按当前顺序导出为一个 PDF”，得到包含全部剩余页面的新文件。
    • 提取页：选中需要的页（可以在输入框里写 1-3,8 快速选中），点“只导出选中的页”。
    • 拆分：选择每页一个文件、每 N 页一个文件，或按范围（如 1-5,6-10，每段一个文件），点“拆分”后逐个下载。
  4. 原文件不会被修改，导出的是一份新的 PDF。页码都按“页面”区域当前的顺序计算。

常见问题

我的文件会被上传吗？

不会。读取、预览和生成 PDF 都在你的浏览器里完成，本页没有上传接口。关闭或刷新页面后，已加载的文件就从内存中清除了。

为什么加了密码的 PDF 打不开？

本工具不处理加密的 PDF，也不提供移除或破解密码的功能。如果这是你自己的文件，请在原来的阅读器或编辑软件里输入密码打开，另存或打印为一份不加密的 PDF，再拿来处理。有些文件虽然打开时不用密码，但设置了“禁止编辑”之类的权限，这类文件同样不处理，请尊重文件作者的设置。

旋转会让页面变模糊吗？

不会。旋转只修改页面的显示方向，文字、图片保持原样，不会被重新压缩。

书签、表单、超链接会保留吗？

页面上看到的内容（文字、图片、矢量图形）和大部分注释会保留；目录书签不会带到新文件里；可填写的表单在合并或拆分后可能无法再填写，建议先填好并保存，再来合并。

拆分后每个文件为什么没有小多少？

PDF 里的字体、背景图等资源常被多页共用，拆分时每个新文件都要带上自己用到的那一份，所以几个小文件加起来通常比原文件大。这是正常现象。

能处理多大的文件？

取决于设备内存。电脑上几十 MB、几百页的文件一般没问题；手机上建议单次处理的总量控制在几十 MB 以内。页数很多时缩略图会逐页生成，稍等即可，不影响导出。

和“图片转 PDF”有什么区别？

图片转 PDF 把 JPG / PNG 照片排成 A4 页面生成 PDF；本工具处理已有的 PDF 文件。两者可以配合使用：先把扫描照片转成 PDF，再和其他 PDF 合并。
