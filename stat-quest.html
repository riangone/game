🌱 4級・3級 記述統計の基礎
  • 代表値 (Mean / Median / Mode) 平均値は外れ値の影響を受けやすく、中央値はロバスト（頑健）。左右非対称な分布では最頻値・中央値・平均値の順に並ぶ。
  • 分散と標準偏差 平均からの偏差平方和をデータ数で割ったもの。 s = √[ (1/n) Σ(xi - x̄)² ]
  • 四分位範囲 (IQR) と箱ひげ図 第3四分位数 (Q3) - 第1四分位数 (Q1)。 外れ値判定境界: Q1 - 1.5×IQR 以下, Q3 + 1.5×IQR 以上
  • ピアソンの相関係数 (r) -1 以上 +1 以下の値を取り、直線的な相関の強さを表す。外れ値に敏感。
🏛️ 2級 推測統計と仮説検定の要点
  • 中心極限定理 (CLT) 標本サイズ n が十分大きければ、母集団の分布に関わらず標本平均は正規分布に従う。 X̄ ~ N(μ, σ²/n)
  • 95% 信頼区間 (母分散既知) 母平均 μ に対する標準的な区間推定。 [ x̄ - 1.96(σ/√n), x̄ + 1.96(σ/√n) ]
  • 第1種の過誤 (α) と第2種の過誤 (β) 第1種の過誤: 真の帰無仮説を誤って棄却（偽陽性）。検出力は 1 - β。
  • カイ二乗 独立性の検定 分割表における期待度数 E と観測度数 O の乖離度合い。 χ² = Σ [ (O - E)² / E ]
⚙️ データサイエンス (DS) と機械学習
  • 混同行列の評価指標 適合率 = TP / (TP + FP), 再現率 = TP / (TP + FN) F1-Score = 2 × (Prec × Recall) / (Prec + Recall)
  • 正則化 (L1 Lasso / L2 Ridge) L1正則化は不要な特徴量の係数をゼロにし疎化（特徴量選択）。L2正則化は極端な係数を縮小。
  • ROC曲線とAUC 縦軸: TPR (再現率), 横軸: FPR (1-特異度)。ランダム予測は AUC=0.5、理想は AUC=1.0。
👑 準1級 / DSエキスパート 高度解析
  • 主成分分析 (PCA) 共分散行列の固有値分解により、分散が最大となる直交軸を合成する次元削減法。
  • ベイズの定理と事後分布 データ D を得た後のパラメータ θ の確率分布。 P(θ | D) ∝ P(D | θ) × P(θ) (尤度 × 事前分布)
  • 因果推論 (傾向スコアマッチング) 共変量による選択バイアス（交絡）を調整し、真の処置効果 (ATE) を推定。
